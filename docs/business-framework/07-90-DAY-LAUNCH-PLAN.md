# 07 - The 90-Day Launch Plan

## Week-by-Week Execution

No theory. No "when you feel ready." Specific actions, specific deadlines,
specific outcomes. Follow the plan or change the plan -- but don't wing it.

---

## Phase 1: BUILD (Weeks 1-2)

### Week 1: Foundation

**Day 1-2: Finalize Your Offer**

```
[ ] Complete Section 01 (Business Model Selection)
[ ] Complete Section 02 (Offer Architecture)
[ ] Define all three pricing tiers
[ ] Write your positioning statement
[ ] Get feedback from 3 people in your target market (not friends/family)
    Ask: "Would you pay $X for this? Why or why not?"
```

**Day 3-4: Set Up Payment & Legal**

```
[ ] Create Stripe account
[ ] Set up invoice template
[ ] Create SOW/contract template (AI-generated, lawyer-reviewed if >$5K deals)
[ ] Set up business bank account (separate from personal)
[ ] Get basic business insurance if needed for your industry
[ ] Choose business structure (sole prop is fine to start -- don't overthink)
```

**Day 5-7: Build Your Tech Stack**

```
[ ] Set up primary AI tool (Claude or ChatGPT Pro)
[ ] Create project management system (Notion workspace)
[ ] Set up Calendly with discovery call link
[ ] Create professional email (Google Workspace)
[ ] Set up CRM (Notion or HubSpot free)
[ ] Create Loom account for client walkthrough videos
```

### Week 2: Delivery System

**Day 8-10: Create Service Delivery Templates**

```
[ ] Build intake form (Tally/Typeform/Google Forms)
[ ] Create SOW template (AI-generated)
[ ] Write kickoff email template
[ ] Build delivery package template
[ ] Write project completion email template
[ ] Create revision request process
[ ] Document full delivery workflow as SOP
```

**Day 11-12: Build Your AI Prompt Library**

```
[ ] Write and test 5-10 core delivery prompts (see Section 09)
[ ] Run each prompt 3x and refine for consistency
[ ] Create prompt templates with variable slots for client customization
[ ] Document which AI tool works best for each task
[ ] Set up prompt storage system (Notion database)
```

**Day 13-14: Create Proof**

```
[ ] Complete 2-3 mock projects using your full delivery process
[ ] Time yourself -- note actual hours per deliverable
[ ] Screenshot/record results for portfolio
[ ] Write up each mock project as a mini case study
[ ] Build a simple portfolio (Notion page, Carrd site, or LinkedIn featured)

NOTE: Mock projects are NOT fake testimonials. They're sample work showing
what you can deliver. Label them as "sample projects" honestly.
```

**Week 1-2 Exit Criteria:**
- [ ] Offer defined with three pricing tiers
- [ ] Full tech stack operational
- [ ] Delivery workflow documented and tested
- [ ] 2-3 portfolio pieces ready
- [ ] You can describe your offer in one sentence

## Phase 2: VALIDATE (Weeks 3-6)

### Week 3-4: First Outreach Sprint

**Daily actions:**

```
MORNING (1 hour):
[ ] Identify 10 potential clients (use LinkedIn, Twitter, communities)
[ ] Research 7 of them (find something specific to personalize outreach)
[ ] Send 7 personalized outreach messages

AFTERNOON (30 min):
[ ] Follow up on yesterday's messages (if no response after 3 days)
[ ] Respond to any replies within 2 hours
[ ] Book discovery calls same-day when possible
```

**Weekly targets:**

```
Week 3: 35 outreach messages → 4-5 responses → 1-2 calls → 0-1 clients
Week 4: 35 outreach messages → 4-5 responses → 2-3 calls → 1-2 clients
```

**Discovery call protocol:**

```
Before call:
[ ] Research their business for 10 minutes
[ ] Prepare 3 personalized observations
[ ] Have pricing tiers ready

During call (15 min max):
[ ] Ask about their situation (5 min)
[ ] Identify their core problem (3 min)
[ ] Present your solution (5 min)
[ ] Handle objections and close (2 min)

After call:
[ ] Send proposal within 2 hours (AI-generated, you customize)
[ ] Follow up if no response in 48 hours
[ ] Follow up once more at day 5
[ ] After that, move on
```

### Week 5-6: Deliver and Document

**For each client:**

```
[ ] Execute full delivery workflow
[ ] Time every step (this data is gold for optimization)
[ ] Over-deliver on first project (build goodwill for testimonial)
[ ] Request testimonial immediately after positive feedback
[ ] Ask for referral using the script from Section 03
[ ] Document what worked and what didn't
[ ] Refine prompts based on actual client feedback
```

**Pricing adjustment:**

```
IF closing > 50% of proposals: Raise prices 20% for next client
IF closing < 20% of proposals: Refine offer or lower Tier 1 price
IF getting pushback on scope: Tighten SOW boundaries
IF revisions exceed 2 rounds: Add revision limits to SOW
```

**Week 3-6 Exit Criteria:**
- [ ] 3-5 paying clients served
- [ ] At least 2 testimonials collected
- [ ] Actual time-per-client data recorded
- [ ] Revenue: $2,000-5,000+ earned
- [ ] At least 1 referral received
- [ ] Delivery process refined based on real experience

## Phase 3: SCALE (Weeks 7-10)

### Week 7-8: Launch Content Engine

**Set up your content system:**

```
[ ] Choose primary platform (LinkedIn for B2B, Twitter for tech/creator)
[ ] Create content calendar template (Notion)
[ ] Write 20 content pieces using AI (batch production)
[ ] Schedule first 2 weeks of posts
[ ] Set up lead magnet (AI-created checklist/template/guide)
[ ] Create landing page for lead magnet (Carrd or ConvertKit)
[ ] Set up email capture
```

**Content cadence:**

```
WEEKLY PRODUCTION (2 hours total):

Monday: Batch-create 5 posts with AI (40 min)
Tuesday: Edit and schedule posts (20 min)
Wednesday: Write newsletter draft with AI (30 min)
Thursday: Edit newsletter and send (20 min)
Friday: Engage with comments/replies (10 min)
```

**Content mix:**

```
Post 1 (Mon): Problem-aware -- name a pain your audience has
Post 2 (Tue): How-to -- teach something valuable
Post 3 (Wed): Case study -- share a client win (with permission)
Post 4 (Thu): Behind-the-scenes -- show your process
Post 5 (Fri): Direct offer -- CTA to work with you or get lead magnet
```

### Week 9-10: Scale Outreach + Inbound

**Continue outbound:**
```
[ ] 5-7 outreach messages per day (now with case studies attached)
[ ] Follow up on all warm leads
[ ] Re-engage past prospects who said "not now"
```

**Build inbound:**
```
[ ] Publish content consistently (5x/week)
[ ] Engage with 10 accounts in your target market daily (15 min)
[ ] DM people who engage with your content (warm outreach)
[ ] Guest post or appear on 1-2 podcasts (pitch using AI)
```

**Weekly targets:**

```
Week 7:  2 new clients (total: 5-7)
Week 8:  1-2 new clients (total: 6-9)
Week 9:  1-2 new clients (total: 7-10)
Week 10: 1-2 new clients (total: 8-12)
```

**Week 7-10 Exit Criteria:**
- [ ] Content publishing on schedule
- [ ] Email list growing (target: 100+ subscribers)
- [ ] 8-12 total clients served
- [ ] Monthly revenue: $5,000-8,000
- [ ] At least 30% of leads coming inbound (content/referrals)
- [ ] 5+ testimonials collected

## Phase 4: SYSTEMATIZE (Weeks 11-12)

### Week 11: Document Everything

```
[ ] Write SOPs for every repeatable process:
    - Client onboarding
    - Service delivery (step by step)
    - Quality assurance
    - Client communication cadence
    - Invoicing and payment follow-up
    - Content creation workflow
    - Outreach process

[ ] Organize prompt library:
    - Categorize by function (delivery, marketing, operations)
    - Note which prompts work best with which AI tool
    - Record average output quality (1-5 rating)
    - Document customization variables

[ ] Create client handoff templates:
    - Onboarding welcome packet
    - Project kickoff doc
    - Progress update template
    - Final delivery template
    - Offboarding/review request
```

### Week 12: Optimize and Prepare for Scale

```
[ ] Analyze time data:
    - Which tasks take longest? Can AI handle more?
    - Which clients are most profitable? Get more of those.
    - Which services have highest margin? Push those.

[ ] Create referral program:
    - Define incentive (10% discount, bonus service, gift card)
    - Write referral request email (AI-drafted)
    - Set up tracking (simple spreadsheet is fine)

[ ] Build email nurture sequence:
    - 7-email sequence (AI-written, you edit)
    - Set up automation (ConvertKit/Mailerlite)
    - Test sequence end-to-end

[ ] Financial review:
    - Actual revenue vs. projections
    - Tool costs vs. value delivered
    - Effective hourly rate calculation
    - 90-day projection for next quarter
```

**Week 11-12 Exit Criteria:**
- [ ] All SOPs documented
- [ ] Prompt library organized and rated
- [ ] Referral program live
- [ ] Email sequence running
- [ ] Clear picture of unit economics

## Phase 5: OPTIMIZE (Week 13+)

### Monthly Recurring Actions

```
WEEK 1 OF EACH MONTH:
[ ] Review last month's numbers (revenue, clients, hours, margin)
[ ] Raise prices if closing rate > 50%
[ ] Cancel tools you didn't use
[ ] Audit prompt performance -- update underperformers

WEEK 2:
[ ] Batch-create month's content
[ ] Plan any new lead magnets or offers
[ ] Follow up with past clients (re-engagement)

WEEK 3:
[ ] Test one new acquisition channel
[ ] Optimize best-performing content
[ ] Review and update SOPs

WEEK 4:
[ ] Financial forecasting for next month
[ ] Strategic planning (15 min -- not 5 hours)
[ ] Client satisfaction check-ins
```

### The $10K/Month Milestone Checklist

You're at $10K/month when:

```
[ ] 8-15 clients per month (depending on pricing)
[ ] 60%+ revenue from Tier 2 and Tier 3
[ ] 30%+ leads coming inbound
[ ] Delivery takes < 5 hours per client average
[ ] Profit margin > 85%
[ ] You've raised prices at least once
[ ] You have a waitlist or can afford to turn down work
[ ] Content publishing is consistent without heroic effort
[ ] Client retention/repeat rate > 30%
```

## If You're Behind Schedule

This is normal. The plan is aggressive on purpose. Here's how to adjust:

**Behind on clients (< 3 by week 6):**
- Double outreach volume to 15/day
- Lower Tier 1 price to remove friction
- Offer 3 free projects in exchange for testimonials
- Post about your expertise daily on LinkedIn/Twitter
- Ask everyone you know: "Do you know anyone who needs [X]?"

**Behind on revenue (< $3K by week 8):**
- Focus on higher-paying clients (stop chasing small deals)
- Add urgency: "I have 2 spots left this month"
- Upsell existing clients to Tier 2
- Launch a limited-time package deal

**Behind on systems (week 12 and still manual):**
- Block 4 hours to document your top 3 processes
- You don't need every SOP -- just the delivery workflow
- Good enough documentation beats perfect documentation never written

The plan adapts. The execution doesn't stop.
